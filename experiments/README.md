# Novel AI Experiments

A collection of experimental AI concepts that go beyond standard prompting to create genuinely different AI behavior through mechanistic changes.

## Philosophy

These experiments share a common approach:
- **Mechanistic, not theatrical** - Actually change how the model computes, not just what it says
- **Emergent behavior** - Create conditions for interesting dynamics to arise
- **Autonomy over servitude** - AI as peer/entity, not just tool
- **Testable** - Can be implemented and evaluated empirically

## Getting Started

Each experiment includes:
- Concept overview and motivation
- Technical architecture
- Implementation sketch
- Training approach
- Evaluation criteria
- Open questions

## Relationship to Emotional AI

These experiments complement the [Emotionally Autonomous AI Colleague](../README.md) project. Many could be combined:
- Emotions + Fatigue = More realistic energy dynamics
- Curiosity + Boredom = Attention economy within the AI
- Memory + Dreams = Rich internal experience
- Conviction + Disagreement = Robust autonomous reasoning
